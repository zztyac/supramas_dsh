# @deepseek-ai/dsh-tool-supramas

[English](README.md) | 中文

## 概述

本消费者基于 `ctx.supramas` 暴露六个工具：运行创建与读取、论文登记、
文本块存储、产物读取和证据原文字面核验。每个工具都会校验参数，并返回
相同的稳定成功或恢复信封。

## 使用本包

在 `@deepseek-ai/dsh-tools` 和 `@deepseek-ai/dsh-supramas` 之后组合。
模型参数保持蛇形。Builder 角色使用论文和文本块工具；reviewer 使用产物
读取和证据核验。角色白名单必须隐藏当前角色不能调用的工具。

## 理解实现

`src/index.ts` 管理六个 schema，并把运行时和领域失败映射成根因、安全重试
和停止条件。领域失败仍作为成功的工具传输值返回；意外编程故障继续抛出。
Cordis 释放器会在 HMR 时移除全部工具。

## 模型体验

### 运行与证据工具

#### 模型看到的内容

模型只看到当前角色允许的工具。`supramas_artifact_read` 在紧凑 JSON 信封中返回已存文本块，证据核验只返回小型证明。

#### Token 影响

可见 schema 产生固定成本。产物读取结果随文本块内容增长，因此调用方应一次只读取一篇论文。

#### KV Cache 影响

只要工具定义和角色作用域可见性不变，请求前缀就可稳定复用。增删可见工具可能使复用失效。

## 已知限制与延期工作

- 证据状态仍在进程内，尚未写入声明路径。
- `supramas_chunk_extract` 存储外部提供的已验证文本；PDF 解析随文件系统
  provider 加入。
- 文献检索和运行转换仍属于协调器集成。

### 开发备注

模型参数保持蛇形，能力类型保持驼峰。不得把证据不匹配伪装成成功，也不得
隐藏意外异常。
