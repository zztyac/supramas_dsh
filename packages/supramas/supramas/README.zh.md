# @deepseek-ai/dsh-supramas

[English](README.md) | 中文

## 概述

本能力注册 `ctx.supramas`，为材料科学任务提供确定性的运行注册表。每次运行拥有稳定的 `supramas:<jobId>` 标识、比较并交换版本、受约束的阶段图、归属明确的产物路径和结构化失败详情。本包还定义四个 Stage 0/1 角色及其精确工具白名单。

## 使用本包

应在所有 SupraMAS 工具消费者之前挂载该服务。使用规范的 `runs/<jobId>` 路径创建运行，保存返回的版本号，并在每次转换时提交该版本。过期写入、非法转换、重复任务或错误失败记录都会抛出稳定的 `SupraMasError` 代码。

## 理解实现

`src/types.ts` 定义公开生命周期值，`src/roles.ts` 管理角色权限，`src/index.ts` 校验请求和转换。返回的快照均为隔离副本。M1 有意使用进程内映射；M3 会在保持能力边界不变的前提下替换存储。

## 模型体验

### 角色权限元数据

#### 模型看到的内容

模型不会直接看到本包内容。消费者在为协调器或子智能体构建工具目录时，把 `ROLE_SPECS` 用作白名单。

#### Token 影响

本包自身没有 token 开销；所选消费者工具决定 schema token。

#### KV Cache 影响

没有直接影响。消费者修改角色可见工具列表时，会改变该智能体的请求前缀，并可能使缓存复用失效。

## 已知限制与延期工作

- M1 状态不会跨进程重启保存。
- 角色 schema 当前只有身份定义；Stage 1 领域包会加入结构化结果校验器。
- 文献检索和证据持久化不属于本包。

### 开发备注

扩展阶段图或角色工具列表时必须同步更新契约测试。终态有意保持不可变，只有可恢复失败允许重新进入运行态。
