# @deepseek-ai/dsh-supramas

[English](README.md) | 中文

## 概述

本能力注册 `ctx.supramas`，为材料科学任务提供确定性运行注册表。每次运行
拥有稳定标识、比较并交换版本、受约束阶段图、规范产物路径、角色白名单，
以及由 `@deepseek-ai/dsh-supramas-domain` 提供的隔离 Stage 1 证据目录。

## 使用本包

在所有 SupraMAS 工具消费者之前挂载本服务。用规范 `runs/<jobId>` 路径
创建运行，保留版本用于状态转换，再按返回的运行标识登记论文和证据文本块。
读取和核验始终返回隔离副本。

## 理解实现

`src/types.ts` 定义生命周期值，`src/roles.ts` 管理角色权限，`src/index.ts`
校验转换并把证据语义委托给领域包。M2 有意把两类映射保留在进程内；M3
会在保持能力方法不变的前提下替换存储。

## 模型体验

### 能力与角色元数据

#### 模型看到的内容

模型不会直接看到本包。消费者把 `ROLE_SPECS` 转成有作用域的工具白名单，并通过面向模型的工具暴露能力方法。

#### Token 影响

本包自身没有 token 开销；所选消费者 schema 决定成本。

#### KV Cache 影响

没有直接影响。修改角色可见工具会改变请求前缀，并可能使复用失效。

## 已知限制与延期工作

- 在 M3 之前，运行和证据状态不会跨重启保存。
- M2 记录规范本地路径，但不把文件写入磁盘。
- 文献检索和科学审查决定仍由独立角色负责。

### 开发备注

不要在缺少测试时扩展生命周期转换或角色工具列表。保持领域校验位于现有
能力边界之后，使持久化变化时模型工具仍然稳定。
